# Копирование, сохранение, медиа и файлы, Избранное, UI/UX

Срез: `origin/dev` @ `a465dbcd` (17.10.2026). Проверка статическая, по коду. Живые прогоны в рамках аудита не выполнялись.
Пути даны от корня репозитория. «Б» — бэкенд (`backend-v2/`), «Ф» — фронт (`frontend/`).

Итого по пунктам: **Готово — 16, Частично — 12, Нет — 2, Нужна ручная проверка — 7** (всего 37; «Копирование» из раздела 6 повторяет «Копировать медиа» из 4.7 и посчитано дважды).

Главное:
- **«Избранного» в интерфейсе нет.** Бэкенд сделал его как чат с самим собой (#719 закрыта), но фронт этот тип чата не знает, и открыть «Избранное» неоткуда.
- **Пересылка медиа на прод-сборке, вероятно, не работает.** Файл читается через `fetch(blob:)`, а CSP от `edge` в `connect-src` не пускает `blob:`. Нужна живая проверка на сборке, которую отдаёт `edge`.
- **Прогресса загрузки нет.** Пока файл грузится, видны только «часы».
- **Ошибка скачивания выглядит как «ошибка расшифровки».** Повторить скачивание нельзя.
- **Типы файлов никто не проверяет.** Фронт показывает в окне выбора только подсказку `accept`, бэкенд для шифрованных вложений тип не проверяет.

## Риски и зависимости

- **Скачивание сейчас публично.** До влития #986 / PR #995 любой, кто знает UUID, получает шифровку и открытые метаданные (имя, MIME, размер, iv). После влития фронт покажет 403 как «ошибку расшифровки». Поэтому сообщения об ошибках скачивания стоит развести до PR #995 или вместе с ним.
- **PR #995 сломает стикеры, если влить его как есть** после пересборки ветки (нет пути для объектов каталога из #973), и вернёт перекачку аватарок при каждом запуске PWA. Дополнительно — конфликт номера миграции 0039.
- **Вытеснение расшифрованного медиа:** реестр держит 300 МБ (`frontend/src/entities/media/model/mediaObjectUrls.ts:24`) и при переполнении отзывает старые `blob:`-адреса (`:59-64`), хотя кеш ленты на них ещё ссылается. После двух-трёх больших видео «Скачать» или «Переслать» у вытесненного файла может молча не сработать, пока лента не перезапросится. Нужна ручная проверка.
- **Без ленивой загрузки большие файлы тормозят чат:** `fetchMessagesPage` ждёт `Promise.all` по всем сообщениям страницы, включая скачивание и расшифровку каждого вложения (`MessageService.ts:78-84, 554-557`); входящее сообщение по сокету — так же (`useServerEvents.ts:63`). Одно видео на 100 МБ задерживает показ всей страницы.
- **Лимит прокси на проде** (не меньше 140 МиБ) настраивается вне репозитория (`docs/deployment.md:63-69`). Без живой проверки на Amvera 100 МБ может снова упираться в 413.
- **Нет браузерных E2E** (#277). Расхождения между dev-сервером и сборкой от `edge` (CSP, cookie) проявляются только на проде — так уже было с «Перевести» (#982).
- **Self-chat на фронте:** если человек найдёт себя в поиске и откроет чат, фронт получит `type: 'self'`, которого не знает. Как это отрисуется — нужна ручная проверка.
