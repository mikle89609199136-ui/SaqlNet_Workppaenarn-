## Риски и зависимости
- **Серверное `theme=system` уже принимается (#1040), клиент — нет.** Если значение придёт из API или старого клиента, `data-theme="system"` даст светлые токены (`themes.css`: `:root` — светлая), а в выборе темы ничего не будет отмечено. Закрывается в #728; до этого не выставлять `system` с других клиентов.
- **#728 и #725 — большие fullstack-задачи на одном исполнителе (p-force).** Это критический путь области: из 13 «Нет» 7 закрывает #728, по одному — #1041 (синхронизация) и #725 (звук сообщения), 4 (анимации/GIF) без задачи; оба «Частично» по уведомлениям — тоже #725. #725 частично зависит от #1042 (`silent`), #728 — от #1041.
- **Web Push на проде зависит от секретов VAPID**: по коду не проверить. Без них переключатель «На этом устройстве» неактивен. На iOS push работает только после установки PWA.
- **Глобальный выключатель уведомлений сейчас обманчив**: push выключается, но fallback-уведомления во вкладке и рингтон остаются. Пользователь видит «выключено» и всё равно получает уведомления.
- **Персональный mute виден, но недоступен**: у чата с mute с другого клиента или из API есть иконка, но снять её из UI нельзя.
- **Звонки при запрете**: пока нет #1056, кнопки звонка видны. В PR #1054 отказ показывается как «отклонён» без объяснения.
- **Конфликт требований по анимациям** между черновиком и #728 — до решения пункт не планируется.
- Тесты не запускались. Выводы о поведении сделаны по коду, E2E на двух устройствах (синхронизация, push, mute) не выполнялись.
