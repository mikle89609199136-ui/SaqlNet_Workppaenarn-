Краткий итог

Исправлено

TanStack Query заменил вечный Map-кеш. Исправлены реакции realtime, pin/unpin cache, pagination, optimistic outbox, retry/cancel и смешивание чатов.

Работает частично

Read receipts, edit timestamps, delete modes, forwarded attribution и media actions не закрывают весь MVP-контракт.

Не подключено

Избранное и message search готовы на backend, но отсутствуют в frontend. Rich-text formatting отсутствует с обеих сторон как законченный контракт.

Приоритет до MVP

  1. Переделать read receipts: idempotent batch по message IDs, per-user/per-message readAt, realtime delivery/read и markers в UI.
  2. Согласовать E2E forwarding contract: server endpoint не может копировать ciphertext между чатами; нужен client re-encryption с подписанной attribution metadata.
  3. Добавить delete-for-self storage/API и выбор режима удаления.
  4. Подключить готовые backend favorites и message search endpoints.
  5. Зафиксировать rich-text data model до реализации toolbar/renderer.
  6. Добавить idempotency key для send и batch contracts для multi-forward/delete.
