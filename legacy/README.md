# Устаревший код

Здесь лежит то, что заменено, но пока не удалено.

## `mobile-client/`

Клиент до перехода на React — 72 файла. **Ничем не собирается и не раздаётся.**

Проверено:

- edge-сервер отдаёт только `FRONTEND_DIR` (по умолчанию `../dist`), то есть сборку Vite из `frontend/` — см. `backend-v2/cmd/edge/main.go`;
- в `infrastructure/` ни одного упоминания, `clientDockerfile.txt` пустой;
- в `frontend/package.json` его нет;
- последняя содержательная правка — август 2026, и та в общем рефакторинге репозитория.

Внутренние ссылки вида `/client/mobile/...` в его же файлах оставлены как были: каталог заморожен, и переписывать пути внутри него незачем. Если код когда-нибудь понадобится оживить, их придётся поправить на `/legacy/mobile-client/...`.

### Что от него ещё зависит

- `frontend/public/logo.png` (364 КБ) и `frontend/public/server-down.html` — на них ссылается только этот клиент. Оба попадают в сборку и грузятся впустую. Удалить их можно вместе с решением по каталогу.
- `frontend/public/call.html` подключает `/client/mobile/scripts/i18n.js`, но **этого файла нет в репозитории** — он был удалён раньше, а тег остался. Из-за этого больше десятка атрибутов `data-i18n` на странице звонка не обрабатываются, и она всегда показывается на русском.

### Почему не удалён

Решение владельца: код может ещё понадобиться как справочный материал. Git всё помнит, так что удалить можно в любой момент — вопрос только в том, вынесено ли из него всё нужное.

Описание его устройства — `docs/client-clean-architecture.md`.
